# Hash‑based project URLs

## Approach: `#project‑id` (fragment / hash)

- No server config — works on any static host (GitHub Pages, Netlify, local `file://`)
- No hardcoded domain — URLs are relative (`/#project-id`)
- Browser back/forward handled by `hashchange` event
- Project IDs with special characters (`×`, `カ`, spaces) are encoded via `encodeURIComponent` / `decodeURIComponent`

## Files to change

**`app.js`** — three additions

### 1. Hash helpers and handler (add after `var gallerySources …`)

```js
var _ignoreHash = false;

function setProjectHash(projectId) {
  _ignoreHash = true;
  window.location.hash = projectId ? "#" + encodeURIComponent(projectId) : "";
  setTimeout(function () { _ignoreHash = false; }, 0);
}

function handleHashChange() {
  if (_ignoreHash) return;
  var raw = window.location.hash.replace(/^#/, "");
  if (!raw) {
    if (activePanelId === "detail") hideDetail();
    return;
  }
  if (!projects || !projects.length) return;  // data not loaded yet
  var id = decodeURIComponent(raw);
  var idx = projects.findIndex(function (p) { return p.id === id; });
  if (idx < 0) return;
  if (activePanelId !== "detail" || selectedProjectIndex !== idx) {
    showDetail(idx, "direct");
  }
}
```
